# Ícones dos acessos rápidos

Coloque ou substitua arquivos PNG nesta pasta com os nomes abaixo. O PM-Painel
usa o PNG automaticamente na próxima abertura; enquanto um arquivo não existir,
ele mostra uma letra ou símbolo como fallback.

| Serviço | Arquivo PNG |
| --- | --- |
| Chrome / Google | `google.png` |
| YouTube | `youtube.png` |
| Outlook | `outlook.png` |
| Teams | `teams.png` |
| Word Web | `word.png` |
| Excel Web | `excel.png` |
| OneDrive Web | `onedrive.png` |
| Google Drive Web | `google_drive.png` |
| Classroom | `classroom.png` |
| Discord Web | `discord.png` |
| GitHub | `github.png` |
| Git Bash | `git.png` |

Recomendação: use imagens quadradas, preferencialmente PNG de 128 x 128 pixels
com fundo transparente. Não é necessário editar o código ao trocar um ícone.
